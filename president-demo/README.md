# เดโมระบบซ่อมบำรุงเพรซิเดนท์ฟลาวมิลล์

จากโฟลเดอร์โครงการ รัน `npm run dev:president` แล้วเปิด [http://127.0.0.1:8081/](http://127.0.0.1:8081/) รัน `npm run build:president` เพื่อสร้างไฟล์เว็บที่ `president-demo/dist/` สำหรับเปิดผ่าน HTTP server

## วิธีทดลอง

1. เปิด **แผนบำรุงรักษา** แล้วเลือกเดือน สัปดาห์ หรือค้นหารหัสเครื่อง จากนั้นกด **เปิดงาน** เพื่อกำหนดวันนัดและผู้รับผิดชอบจากแผนกซ่อมบำรุง
2. กด **เพิ่มแผน PM** เพื่อเพิ่มงานจากทะเบียนเครื่องจักร รอบบำรุงรักษาเป็นข้อมูลของแต่ละงาน ตารางประจำปีแสดงรอบที่ระบุไว้ใน Master Plan และงานที่เพิ่มเอง
3. เปิด **บันทึก AIR JET FILTER** เพื่อบันทึกผลและค่าแรงดันตามรอบเวลา แบบฟอร์มจะแสดงข้อความเมื่อค่าแรงดันเกิน 20 mbar
4. เปิด **แจ้งซ่อม** เพื่อสร้างใบแจ้งและปิดงานเมื่อกรอกผลซ่อมแล้ว

เดโมใช้ข้อมูลที่เตรียมจากไฟล์แนบและเก็บรายการที่บันทึกเพิ่มเติมในเบราว์เซอร์เครื่องนั้น บุคลากรในทะเบียนเป็นข้อมูลอ้างอิงสำหรับเดโม การใช้งานเป็นแบบเปิดในเครื่องโดยไม่ต้องลงชื่อเข้าใช้
